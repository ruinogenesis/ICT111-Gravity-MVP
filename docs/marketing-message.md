## Message Quality Check
- Clear within 5 seconds: each message opens with the situation (moving out) or the product in one clause. ✓
- Identifies target user: "RSU students" / "moving out" in every message. ✓
- Explains problem or benefit: scattered groups, wasted items, private contact. ✓
- Includes one action: exactly one CTA per message. ✓
- Avoids exaggerated claims: no "guaranteed", no "safe", no feature not in v0.3; demo labelled as sample data (Lab 09 R-06 wording rule). ✓
